# Compute Scale Scores

Uses the dictionary of a `tidy_sem` object to compute total scores for
each scale.

## Usage

``` r
score_items(x, type = c("mean", "median", "sum"), ...)
```

## Arguments

- x:

  A `tidy_sem` object containing data and a dictionary with item names
  and scale assignments.

- type:

  Character string specifying the scoring method. One of `"mean"`
  (default), `"median"`, or `"sum"`.

- ...:

  Additional arguments passed to the aggregation function, such as
  `na.rm = TRUE`.

## Value

A data frame with one row per observation and one column per scale.
Column names correspond to the scale names in the dictionary.
